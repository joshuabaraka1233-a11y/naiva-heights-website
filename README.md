# Naiva Heights Website

Premium responsive website for Naiva Heights serviced apartments in Karagita, Naivasha, Kenya.

## Run locally

```bash
npm install
npm run dev
```

## Property photography

Place the 19 approved property photographs in `public/gallery/` using the filenames referenced in `app/page.tsx`. Do not substitute stock imagery.

## Notes

- Booking enquiries open WhatsApp at the supplied contact number.
- Rates and availability are confirmed directly by the property.
- Update property details only after owner confirmation.
